# Bundled fonts

Self-hosted so the app makes **no external requests** (only the file hash and
`/raw` fetches ever leave the browser). Both are SIL Open Font License 1.1 —
bundling and redistribution are permitted.

| File | Family | Source |
|---|---|---|
| `besley-800.woff2` | Besley (weight 800) — headlines | Google Fonts, latin subset |
| `plus-jakarta-sans.woff2` | Plus Jakarta Sans (variable 400–700) — body/UI | Google Fonts, latin subset |

Fonts and palette follow the ar.io brand kit (`https://ar.io/brand-kit/agents.json`).
The OFL requires the license text to accompany the fonts; see
<https://openfontlicense.org/> (SIL OFL 1.1). Reserved Font Names: "Besley",
"Plus Jakarta Sans".
